# Midterm Project

For my midterm, I created a personal portfolio website to showcase my creative work, including graphic design, photography, artwork, and interactive projects.

I wanted my website to be easy to navigate while still reflecting my personality and design style.

My main audience is potential employers, recruiters, and internship coordinators who may be interested in my work.

I used a soft pink color palette, editorial typography, and a clean image-based layout.
